# Кіно: аналітична панель

Практична робота №06.
Варіанти: PY-D6P / PR06-C6P.

## Функції
- SQLite: films, views, awards
- Фільтрація за роками, кінотеатром і наявністю awards
- Метрики та аналітичні графіки
- Форма додавання фестивальних записів
- Кешування запитів Streamlit

## Дані
Перегляди синтетичні, навчальні.
Фестивальні відзнаки зібрані із зовнішніх джерел.
Посилання наведені в awards_sources.csv.

## Запуск
pip install -r requirements.txt
streamlit run app.py

## Примітка
У хмарному середовищі зміни локальної SQLite-бази
не гарантують постійного зберігання.
